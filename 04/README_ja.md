# Camp Layout Lab 3D V4

キャンプサイト上で、テント・タープ・車・焚き火・リビング・荷物を配置し、太陽方向・影・実際の風予報・煙の流れを確認するWebプロトタイプです。

## 起動

1. ZIPを展開します。
2. `start.bat` をダブルクリックします。
3. ブラウザで `http://localhost:8000` が開きます。

Pythonが利用できる環境を想定しています。

## V4の主な改善

### 場所検索

検索先を1サービス依存から複数検索へ変更しました。

- OpenStreetMap / Overpass: キャンプ場などの固有施設名を完全一致検索
- 国土地理院 地名・住所検索: 日本国内の地名・住所・一部施設を検索
- Open-Meteo Geocoding: 市町村・地名・郵便番号系を補完
- `35.1234, 139.1234` のような緯度経度入力も検索欄から利用可能
- APIの一部が失敗しても、取得できた検索結果を表示
- 地図クリック・緯度経度直接入力も引き続き利用可能

例: `メープル那須高原キャンプグランド` のような施設名は、OSM側に同名データがあれば施設そのものを候補に表示します。

## 風向・風速の自動取得

右側の「APIから自動取得」をONにすると、基準地点・日付・時刻に合わせて Open-Meteo から時間別データを取得します。

取得項目:

- 10m風向
- 10m風速
- 最大瞬間風速

場所または日付が変わった時だけ1日分を取得し、時刻スライダー操作時は取得済みの時間別データから最も近い時刻を選ぶため、スライダー操作ごとにAPI通信はしません。

風向は気象データ一般と同じく「風がどこから吹いてくるか」を示します。煙表示ではその180度反対側を風下として描画します。

### 予報期間外

将来の風予報には取得可能期間があります。予報期間外の日付では風向を推測せず、「予報期間外」と表示し、煙の風下判定を停止します。

過去の日付は Open-Meteo Historical Weather API を利用する構成です。

### 手動設定

「APIから自動取得」をOFFにすると、従来どおり風向・風速スライダーを手動操作できます。ネットワーク制限がある環境でのフォールバックとして利用できます。

## その他の機能

- 検索候補から基準地点を選択
- 地図を直接クリックして基準地点を決定
- 配置済みの道具を地図上・白紙サイト上のどちらでも再ドラッグ
- ドラッグ中も煙・距離・配置診断を追従
- 2D / 3D表示切替
- MapLibre Terrainによる3D地形表示
- 地理院地図を3D地形上へ重ねて表示
- 車・テント・タープ・焚き火・リビング・荷物を立体ミニチュア風に表示
- 選択物の向き・サイズ変更
- SunCalcによる太陽方位・高度、日の出・日の入
- 風向に応じた煙ゾーン
- JSON保存・読込

## V4 の場所設定

画面左上の「STEP 1 / 場所を検索・設定」は、地図表示・白紙サイト表示のどちらでも常に表示されます。

1. キャンプ場名、地名、住所を入力
2. 「検索」をクリック
3. 候補一覧から「この場所を使う」を選択
4. 選択地点を基準に、日付と時刻に対応した風向・風速を Open-Meteo から取得

「地図上から場所を選択」を押した場合は、自動的に地図表示へ切り替わります。
